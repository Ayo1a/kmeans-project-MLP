# kmeans-project-MLP
## An implementation of the K-means clustering algorithm, with support for custom initialization, convergence control, and visualization of the results. 

This project implements the K-means clustering algorithm from scratch. Given a dataset and a number of clusters K, the algorithm assigns each point to its nearest centroid and updates the centroids iteratively until they stop changing or a maximum number of iterations is reached. The goal of the project was to understand how the algorithm works internally, including centroid initialization, distance computation, and convergence, rather than relying on an existing library.
